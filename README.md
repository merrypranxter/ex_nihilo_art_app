## Deploy when you choose

Compatible with Netlify (config in `netlify.toml`). No automatic deployment or paid service is triggered by this repository. The art runs without Wolfram.

### Optional Wolfram developer AppID

The browser **never** receives your Wolfram AppID.

1. Add `WOLFRAM_APP_ID` as a Netlify environment variable.
2. Set `WOLFRAM_ACCESS_TOKEN` to a **different, long random secret** to protect your API quota.
3. In the Wolfram tab, enter that access token only (not your Wolfram AppID) to unlock on-demand requests. The token is kept in memory for this tab and is not committed or stored as part of your art DNA.
4. Use a Netlify deployment for the serverless function. The Vite dev server alone does not serve Netlify Functions; use `netlify dev` if testing that feature locally.

Wolfram is consulted only when you press **Analyze field**. It receives a numerical 3×3 local field Jacobian, and returns computational analysis. It does *not* drive animation.

## Architecture

- `src/engine.js` — mutable simulation state, flow physics, 3D occupancy, growth and full-world serialization.
- `src/ecology.js` — real three-dimensional nutrient concentration field, finite-difference diffusion, consumption and replenishment.
- `src/colony.js` — synchronous 3D cellular automaton with nutrient-weighted births, mineralization and erosion; no prebuilt object.
- `src/morphogenesis.js` — 3D Gray–Scott reaction–diffusion, local chemistry and nutrient coupling.
- `src/surface.js` — bounded marching-tetrahedra mesh extraction from the B concentration field.
- `src/structural.js` — solid-cell collision solver and trajectory guidance along the evolving chemical isosurface.
- `src/art-direction.js` — procedural vector laws for visual silhouette and artist-facing material configurations.
- `src/branching.js` — exact phyllotactic branch geometry and bounded, deterministic temporal growth rhythms.
- `src/filigree.js` — decaying birth-direction memory and display-only, generation-aware material emphasis.
- `src/mineral-optics.js` — deterministic optical maturity curves and actual tapered prism/facet geometry profile definitions.
- `src/gesture-witch.js` — browser-independent atomic field-source transaction and bounded two-pointer metric/twist map.
- `tests/biology.test.js`, `tests/colony.test.js`, `tests/morphogenesis.test.js`, `tests/structural.test.js`, `tests/art-direction.test.js`, `tests/branching.test.js` — chemistry, cellular dynamics, collisions, porous diffusion, smooth surface normals, branching law, temporal rhythm and checkpoint regression tests (`npm test`).
- `src/main.js` — Three.js renderer, inputs, camera, views and exporting.
- `src/styles.css` — mobile-first control layout.
- `netlify/functions/wolfram.mjs` — credential-protected, allowlisted computational request.
- `docs/ROADMAP.md` — next real simulation and material milestones.

Current limitations: CPU-side growth and chemistry updates, a fixed 28³ morphogen grid, periodic CPU isosurface extraction capped at 14,000 triangles, and finite geometry capacity. This is a first true volumetric reaction–diffusion solver, **not** a fluid dynamics engine or a GPU volume renderer. Crystal collisions use a conservative voxel envelope, not triangle-mesh rigid-body physics; porous walls are implemented as flux reduction across shared cell faces. Undo applies to field-node editing, **not** rewinding all simulation time; save/load uses JSON checkpoints (v3 saves all three engines); PNG export captures the current canvas, not high-resolution cinematic video. We keep these boundaries explicit.

**Principle:** construction DNA (reproducible rules/seed) is different from lived simulation state (where this particular organism has grown).

## What not to assume

No live browser/device benchmark or production Vite build has been run yet. The fiber shape and material adjustments are an implementation candidate; appearance and frames-per-second must be judged in a real WebGL2 browser, not inferred from headless math tests. Artistic finish choices are first-pass light-response settings and must be judged on actual devices; no claim of polished final visuals is made. The environment could not reach GitHub to clone the repo for a local npm install, so code/DOM parsing and standalone headless mathematical-state tests were performed instead. These commits include source-level validation and a headless mathematical-state replay check, but need a normal `npm install && npm test && npm run build` followed by a real iPhone Safari smoke test before release.
